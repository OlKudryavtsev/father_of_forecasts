# v3.8.0 — Multi-tournament foundation

Фундамент для нескольких турниров и архивов прошлых «Отцов прогнозов».

## Что добавлено

- Новая таблица `tournaments` с кодом, названием, типом, годом, статусом, датами, правилами начисления, признаком турнира по умолчанию и порядком отображения.
- Миграция `033_add_tournaments_and_archive_import.sql`:
  - создаёт `tournaments`;
  - регистрирует текущий `wc2026` как `ЧМ-2026`;
  - переводит кэш вероятностей победы на уникальность `league_id + tournament_code`.
- Mini App получил выбор турнира в верхней панели.
- Основные API теперь принимают `tournament_code`:
  - dashboard;
  - список матчей;
  - матч-центр;
  - рейтинг;
  - история гонки рейтинга;
  - прогнозы участников;
  - турнирные прогнозы;
  - аналитика совпадений прогнозов;
  - расклады.
- Для завершённых/архивных турниров включён read-only режим:
  - нельзя менять прогнозы матчей;
  - нельзя менять турнирные прогнозы;
  - не показываются live-расклады победы.
- Добавлен endpoint `GET /api/webapp/tournaments` для списка турниров.
- Добавлен админский endpoint `POST /api/webapp/admin/tournament-archive/import` для универсального импорта архивного турнира.

## Формат архива для импорта

Импорт принимает нормализованный JSON с блоками:

```json
{
  "tournament": {
    "code": "wc2022",
    "name": "ЧМ-2022",
    "status": "archived",
    "starts_at": "2022-11-20T00:00:00Z"
  },
  "league_name": "Отец прогнозов",
  "users": [],
  "matches": [],
  "predictions": [],
  "tournament_predictions": [],
  "tournament_result": {}
}
```

Импорт создаёт недостающих архивных пользователей, матчи, прогнозы на матчи, долгосрочные турнирные прогнозы, итог турнира и добавляет пользователей в указанную лигу.

## Ограничения v3.8.0

- Это фундамент, а не финальная загрузка ЧМ-2022/ЧЕ-2024.
- Фэнтези, Panini, новости, MatchTV/видео и внешняя синхронизация API-Football пока остаются ориентированы на текущий активный турнир.
- Бот-команды в личке/группе пока в основном используют текущий турнир по умолчанию; полноценные команды вида `/table wc2022` лучше делать отдельной версией.
- Для архивов нужен подготовленный JSON с историческими матчами, участниками и прогнозами.
