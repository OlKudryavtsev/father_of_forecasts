# v3.7.7 — аналитика совпадений прогнозов

## Что добавлено

- В раздел **Прогнозы** добавлена карточка **«Кто с кем думал одинаково»**.
- Аналитика считает совпадения по парам участников лиги: Игрок 1 × Игрок 2, Игрок 1 × Игрок 3 и т.д.
- Учитываются только матчи, которые уже начались или завершились.
- Пара сравнивается по конкретному матчу только если оба участника сделали прогноз.
- Добавлен переключатель:
  - **Без прохода** — одинаковым считается только одинаковый прогноз счёта.
  - **С проходом** — для плей-офф дополнительно должен совпасть выбранный проход.
- Добавлен множественный фильтр стадий: туры группового этапа, 1/16, 1/8, 1/4, 1/2, матч за 3-е место, финал.

## API

- Новый endpoint: `GET /api/webapp/predictions/agreement`.
- Параметры:
  - `league_id` — лига;
  - `include_advancement` — учитывать ставку на проход;
  - `stages` — список ключей стадий через запятую.

## Технически

- Миграция БД не требуется.
- Версия Mini App обновлена до 3.7.7.
