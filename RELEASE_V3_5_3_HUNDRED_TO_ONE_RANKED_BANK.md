# v3.5.3 — «Сто к одному»: рейтинги с равными местами и очищенный банк

## Что изменено

- Формат `hundred_to_one` теперь хранит не просто десять произвольных ответов, а строки объективного рейтинга:
  - `position` — место от 1 до 10;
  - `value` — проверяемый показатель строки;
  - `answers` — один или несколько ответов с одинаковым показателем.
- Несколько ответов на одной позиции получают одинаковые очки: `position × 100`.
  - место 1 — 100 очков;
  - место 2 — 200 очков;
  - ...;
  - место 10 — 1000 очков.
- Старые карточки формата «Сто к одному» продолжают работать: простой старый список трактуется как десять последовательных позиций.
- Редактор Банка показывает две колонки для каждой строки рейтинга:
  - ответы через `|` для равных мест;
  - показатель/значение.
- Добавлен готовый файл импорта `content/hundred_to_one_world_cup_history_20.json`:
  - 20 новых вопросов;
  - история мужских чемпионатов мира 1930–2022;
  - только ранжируемые топ-10;
  - значения для каждой строки, поддержка равных мест;
  - источник, тема, теги, сложность и период повторения 180 дней.

## Важно

Новый файл использует расширенную структуру строк с `position`, `value` и `answers`. Для корректного импорта и одинакового начисления баллов при равных местах требуется v3.5.3 или новее.

## Как очистить старые вопросы «Сто к одному»

Рекомендуемый вариант — **архивировать**, а не удалять: история уже сыгранных квизов сохранится.

В PWA: `Квиз → Банк → Сто к одному → Архивировать` для каждой старой карточки.

Для массовой очистки в PostgreSQL сначала сделайте резервную копию, затем архивируйте все текущие вопросы типа `hundred_to_one` выбранной лиги:

```sql
CREATE TABLE league_quiz_questions_backup_20260702 AS
SELECT *
FROM league_quiz_questions
WHERE league_id = 1
  AND question_type = 'hundred_to_one';

UPDATE league_quiz_questions
SET status = 'archived',
    updated_at = NOW()
WHERE league_id = 1
  AND question_type = 'hundred_to_one'
  AND status <> 'archived';
```

Замените `league_id = 1`, если очищаете другую лигу. После архивации импортируйте JSON из Банка и одобрите новые черновики.

Миграция БД не требуется.
