# v3.5.1 — Исправление создания квиза

## Проблема
В обработчике защиты от повторов использовалась модель `League`, но она не была импортирована в `app/services/league_quiz.py`. Из-за этого создание любого нового квиза падало с `NameError: name 'League' is not defined` до постановки Telegram-событий в очередь.

## Исправление
Добавлен импорт `League` из `app.models`.
