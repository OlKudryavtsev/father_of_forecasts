# v3.7.9 — финальный рейтинг после завершения турнира

## Что изменено

- В «Матч-центр» добавлена финальная карточка победителя турнира прогнозов с итоговым количеством очков.
- На вкладке «Рейтинг» скрыты шансы на 1-е место и раздел раскладов после завершения турнира.
- В рейтинге добавлен переключатель баллов: «Всего», «Матчи», «Турнир».
- Для каждого участника показана математика набора очков: точные счета, исходы, проходы и долгосрочные турнирные прогнозы.
- Отключены автоматические турнирные рассылки: утренние новости и ежедневные итоги по лигам/участникам больше не запускаются по расписанию по умолчанию.

## Технически

- Добавлен флаг `TOURNAMENT_SCHEDULED_BROADCASTS_ENABLED=false` по умолчанию.
- Backend `/api/webapp/table` возвращает `points_breakdown`, `tournament_finished` и финальный `tournament_summary`.
- Backend `/api/webapp/match-center` возвращает `tournament_summary` для карточки победителя.
- Миграция БД не требуется.
