# v3.7.8 — топ одинаковых прогнозов в боте и компактная аналитика в Mini App

## Что изменено

- В Mini App секция «Кто с кем думал одинаково» перенесена вниз раздела «Прогнозы», после списка прогнозов.
- По умолчанию показываются только первые 5 пар, остальные раскрываются кнопкой.
- Переключатель «с проходом / без прохода» заменён выпадающим списком.
- Фильтр стадий заменён выпадающим списком с множественным выбором стадий.
- Нажатие на пару открывает модальное окно со списком матчей и прогнозов обоих участников.
- Добавлена команда Telegram `/same` для личных и групповых чатов.
- Добавлена алиас-команда `/agreement`.
- `/same` показывает топ-10 пар по количеству одинаковых прогнозов по начавшимся/завершённым матчам.
- `/same pass` показывает тот же топ с учётом ставки на проход в плей-офф.
