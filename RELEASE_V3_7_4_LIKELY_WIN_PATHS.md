# v3.7.4 — Вероятности победы и вероятные пути к 1-му месту

## Рейтинг

- На карточке каждого участника добавлен показатель **«Шанс на 1-е»**.
- Это модельная вероятность именно единоличного первого места, рассчитанная одной общей симуляцией для всей активной лиги.
- Отец остаётся вне конкурса, поэтому показатель для его строки не выводится.

## Расклады

- Раздел по-прежнему свёрнут по умолчанию; выбор участника остаётся выпадающим списком.
- Вместо редких жёстко заданных комбинаций выводятся до 10 наиболее частых победных путей из симуляции.
- Пути отсортированы по убыванию их доли среди всех симуляций, в которых выбранный участник стал единоличным первым.
- Для каждого пути показаны: типичный диапазон итоговых и дополнительных очков, диапазоны точных счетов / исходов / проходов, часто срабатывающий долгосрок и типичные лимиты основных конкурентов.
- В карточке пути два разных показателя: **доля среди победных путей** и **общий шанс этого пути** среди всех симуляций. Это исключает ситуацию, когда главный видимый показатель почти везде был «<0,1%».

## Модель

- В одном прогоне одновременно моделируются все участники, поэтому для каждого прогона определяется только единоличный лидер; ничьи за первое место не засчитываются как победа.
- Используются текущие ИИ-прогнозы Отца, доступные футбольные данные, текущие прогнозы участников, проходы и только живые долгосрочные ставки.
- Для трофейных прогнозов внутри одного прогона используется общий результат категории, поэтому одинаковые ставки участников не получают несовместимые исходы.
- Модель включает всю оставшуюся сетку: 1/8, 1/4, 1/2, матч за 3-е место и финал.

Миграция БД не требуется.
