# v3.7.3 — Свёрнутые «Расклады» и модельная вероятность

## Что изменилось

### Mini App · Рейтинг → «Расклады»

- Блок «Расклады» свёрнут при первом открытии вкладки «Рейтинг».
- Нажатие на шапку разворачивает расчёт. Запрос к API выполняется только после раскрытия блока.
- Выбор участника заменён на выпадающий список, поэтому длинный перечень участников не занимает экран.
- Для каждого варианта выводится `Вероятность условий: ≈ N%`.
- Если ограничение по очкам относится более чем к трём соперникам, показываются три ближайших и пометка о числе остальных; расчёт учитывает всех релевантных соперников.

### Как считается вероятность

Это модельная оценка выполнения именно условий конкретного варианта, а не букмекерский коэффициент и не обещание итогового места.

1. Для известных оставшихся матчей берётся сохранённый ИИ-прогноз Отца: его прогноз счёта/исхода/прохода и значение «Уверенность».
2. Уверенность ИИ конвертируется в консервативные вероятности попадания в точный счёт, исход и проход. Если участник уже поставил иначе, вероятность соответствующего события корректируется относительно ИИ-прогноза.
3. Для открытых матчей без прогноза и ещё неизвестных будущих пар предполагается, что участник использует будущий ИИ-прогноз Отца; для пары без определённых сборных применяется осторожная базовая оценка.
4. Живые долгосрочные ставки оцениваются по текущему прогнозу Отца на турнир, когда он доступен; иначе применяется консервативная оценка по текущей силе живых сборных. Мёртвые ставки не участвуют.
5. Лимиты ближайших конкурентов учитываются через оценку распределения их будущих очков.

У разных участников совпадают реальные матчи, поэтому события зависимы. Для интерфейса лимиты конкурентов оцениваются отдельно: проценты вариантов могут пересекаться, их нельзя складывать.

## Данные и миграции

- Миграция БД не требуется.
- Внешние букмекерские коэффициенты не используются.
