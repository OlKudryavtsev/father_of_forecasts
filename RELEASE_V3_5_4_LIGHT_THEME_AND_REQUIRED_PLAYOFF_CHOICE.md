# v3.5.4 — контраст светлой темы и обязательный выбор прохода

## Светлая тема
- Контраст основных текстов, вкладок, переключателей, нижней навигации, карточек и полей формы повышен для светлого оформления.
- Вкладки Матч-центра, Турнира и Бомбардиров теперь используют тёмный читаемый текст и отчётливо выделенное активное состояние.
- Блок выбора прохода адаптирован под светлую тему: все три варианта имеют отдельные контрастные состояния.

## Матчи плей-офф
- При сохранении прогноза через PWA обязательным стал один выбор: первая команда, вторая команда или «Без прохода».
- «Без прохода» хранится как явный выбор без ставки и даёт 0 очков за проход; первая и вторая команды сохраняют действующую механику +1 / −1.
- API отклоняет плей-офф-прогнозы без явного поля `advancement_choice`.
- В личном Telegram-боте клавиатура после выбора счёта также требует один из трёх вариантов. Команда `/predict ID СЧЁТ` для плей-офф теперь требует завершение `home`, `away` или `none`.

## Совместимость
- Миграция не требуется.
- Ранее сохранённые прогнозы не пересчитываются и не изменяются. При первом редактировании старого прогноза без прохода отображается вариант «Без прохода».
