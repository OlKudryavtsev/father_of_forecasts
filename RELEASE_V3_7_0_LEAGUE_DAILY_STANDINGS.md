# v3.7.0 — Итоги лиг и расклады на первое место

## Ежедневные итоги в групповых чатах

- После общего сообщения «Итоги дня» бот публикует отдельный компактный итог по каждому активному участнику лиги: набранные очки за сутки, точные счета, исходы, промахи, текущее место и общий счёт.
- В сводку попадают и участники без прогнозов или без очков — никто не сможет незаметно отсидеться в запасе.
- Публичные комментарии используют выбранный для лиги тон юмора. Личные «Твои итоги дня» продолжают использовать персональные настройки участника.
- Доставка работает и для legacy-группы из `GROUP_CHAT_ID`, даже если ID чата ещё не сохранён в настройках лиги.
- Ручная админская отправка утренних итогов использует тот же полный сценарий: общий пост и персональные сообщения во всех группах лиг.

## «Расклады» в рейтинге

- Под таблицей рейтинга появился раздел **«Расклады»** с выбором участника.
- Расчёт выводит до 10 вариантов необходимых условий для **единоличного** первого места: требуемый итог по очкам, комбинацию точных счетов / исходов / проходов, условия по турнирным прогнозам и максимальные допустимые доборы очков ближайшими конкурентами.
- Если лидерство уже математически недостижимо, приложение показывает конкретную причину: доступный максимум и минимум, который нужен для первого места.
- Варианты являются прозрачными условиями по очкам, а не выдуманной единой симуляцией всех оставшихся счетов: прогнозы разных участников могут конфликтовать между собой.

## Команда Telegram

- В привязанном к лиге групповом чате доступна команда `/standings`.
- Любой активный участник лиги выбирает человека кнопкой, после чего бот публикует его расклады в группе.
