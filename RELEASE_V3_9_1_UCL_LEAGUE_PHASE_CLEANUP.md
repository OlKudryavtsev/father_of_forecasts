# v3.9.1 — ЛЧ: только общий этап, русский интерфейс клубов

## Что исправлено

- Скрипт `python scripts/sync_ucl_2026_2027.py` теперь после загрузки из API-Football удаляет матчи квалификации и play-off квалификации.
- Для ЛЧ остаются только 144 матча общего этапа.
- Даты и время матчей общего этапа нормализуются по официальному календарю UEFA.
- Клубы общего этапа сохраняются с русскими названиями.
- Mini App для ЛЧ дополнительно нормализует ответы API на клиенте: показывает русские названия клубов и флаги стран клубов.
- Защитный frontend patch скрывает широкий блок вида «144 матча стартуют одновременно», если провайдер снова отдаст placeholder-дату для большого числа матчей.
- Версия Mini App/PWA поднята до `3.9.1`.

## Что сделать после деплоя

После merge/deploy нужно снова запустить в production environment:

```bash
python scripts/sync_ucl_2026_2027.py
```

Ожидаемый результат после cleanup:

```text
league_phase_cleanup.remaining_matches = 144
league_phase_cleanup.deleted_non_league_phase > 0
league_phase_cleanup.unmatched_kept_count = 0
```

Если `unmatched_kept_count` не равен 0, значит API-Football вернул название клуба в новом формате; нужно добавить alias в `app/services/ucl_2026_2027.py`.
