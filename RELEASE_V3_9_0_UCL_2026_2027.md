# v3.9.0 — ЛЧ 2026/27

## Что добавлено

- Добавлен новый турнир `ucl_2026_2027` — **ЛЧ 2026/27**.
- Турнир автоматически появляется в селекторе турниров Mini App.
- Для ЛЧ включён отдельный скоринг:
  - точный счёт матча: 3 очка;
  - исход матча: 1 очко;
  - победитель турнира: 15 очков;
  - финалист: 10 очков;
  - лучший бомбардир: 15 очков;
  - прогноз на 3-е место отключён, так как в Лиге чемпионов нет матча за 3-е место.
- Для ЛЧ используется текущая лига и текущие участники по умолчанию, при этом пользовательские лиги сохраняют существующую механику.
- Синхронизация матчей ЛЧ 2026/27 из API-Football сделана явной: выбор турнира в Mini App больше не вызывает внешний API и не пишет матчи в БД.
- Синхронизация идемпотентная: при повторном запуске обновляет уже найденные матчи и добавляет новые по `external_fixture_id`, не пропуская импорт из-за ранее загруженной части календаря.
- Для ЛЧ добавлен frontend compatibility patch: скрывается 3-е место, а бомбардир вводится вручную без показа старых WC-only кандидатов.
- Добавлен ручной скрипт синхронизации:

```bash
python scripts/sync_ucl_2026_2027.py
```

## Новые настройки окружения

- `API_FOOTBALL_KEY` — ключ API-Football, обязателен для загрузки матчей.
- `API_FOOTBALL_UCL_LEAGUE_ID` — ID турнира в API-Football, по умолчанию `2`.
- `API_FOOTBALL_UCL_SEASON` — сезон, по умолчанию `2026`.

## Миграция

Добавлена миграция:

```text
db/migrations/034_add_ucl_2026_2027_tournament.sql
```

Перед релизом production DB должна уже содержать изменения миграции `033_add_tournaments_and_archive_import.sql`, включая колонку `league_win_model_cache.tournament_code`.

## Проверка после деплоя

1. Убедиться, что migration `033` уже применена.
2. После merge/deploy применить `034`, если миграции не выполняются автоматически.
3. Запустить в production environment:

```bash
python scripts/sync_ucl_2026_2027.py
```

4. Открыть Mini App.
5. Проверить, что в селекторе турниров появился пункт **ЛЧ 2026/27**.
6. Выбрать ЛЧ 2026/27.
7. Проверить, что в Матч-центре появились матчи ЛЧ.
8. Проверить, что долгосрочный прогноз для ЛЧ содержит победителя, финалиста и бомбардира без 3-го места.
